# BudgetApp – Android

Android klient osobnej finančnej aplikácie **BudgetApp**, vytvorený v **Kotlin** s využitím **Jetpack Compose**.

Aplikácia komunikuje s vlastným backendom vytvoreným v **C# a ASP.NET Core Web API** prostredníctvom REST API.

## 🛠️ Technológie

- **Kotlin**
- **Jetpack Compose**
- **MVVM**
- **ViewModel**
- **StateFlow**
- **Kotlin Coroutines**
- **Retrofit**
- **DataStore**
- **Navigation Compose**

## 📱 O aplikácii

BudgetApp je osobná finančná aplikácia, na ktorej si prakticky prehlbujem znalosti Android vývoja a komunikácie medzi mobilnou aplikáciou a backendom.

Android aplikácia zabezpečuje používateľské rozhranie a komunikuje s backendom prostredníctvom REST API.

## 🏗️ Architektúra

Aplikácia využíva architektonický prístup **MVVM (Model–View–ViewModel)**.

Pri vývoji využívam:

- **Jetpack Compose** na tvorbu používateľského rozhrania
- **ViewModel** na oddelenie UI od aplikačnej logiky
- **StateFlow** na prácu so stavom obrazoviek
- **Coroutines** na asynchrónne operácie
- **Retrofit** na komunikáciu s REST API
- **DataStore** na lokálne uloženie potrebných údajov
- **Navigation Compose** na navigáciu medzi obrazovkami

## 🔗 Backend

Backend projektu je samostatný repozitár vytvorený v C#/.NET:

**[BudgetApp – Backend](https://github.com/martinamotlochova/BudgetApp)**

Backend využíva:

- C#
- .NET 10
- ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL
- REST API
- JWT autentifikáciu
